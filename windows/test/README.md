# Verification

`live.cjs` is opt-in and uses the user's configured VanYo provider; normal runs incur model API usage. It verifies setup IPC (optionally from `TAKT_TEST_MAIN`, a packaged main module), local authentication, two assistant replies, and terminal input/output/resize/close. `TAKT_STYLE_ONLY=1` captures light, dark and compact real pi-web layouts and checks desktop style values without sending model requests. It leaves the client running after success. This test requires an existing local connection configuration.

`config.test.cjs` runs with Node's test runner and checks URL policy and server discovery. `smoke.cjs` runs in Electron, opens the real connection screen and captures `dist/windows/startup.png` after checking the bridge and renderer isolation. These tests require no provider credentials and do not send prompts to an agent.

`provider.test.cjs` checks isolated provider configuration and saved-key reuse. Source delivery validation uses `TAKT_TEST_USER_DATA` for a fresh private profile, `TAKT_TEST_CONFIG` for a private JSON setup input, `TAKT_TEST_PROVIDER` / `TAKT_TEST_MODEL` for the selected model, and `TAKT_TEST_RESULT` for a secret-free report. The live test verifies rendered replies and captures the chat window. Private profiles/config inputs must never be included in release assets.

`installed.cjs` verifies the actual installed EXE using Playwright's Chromium debugging connection. Start the EXE with `--remote-debugging-address=127.0.0.1 --remote-debugging-port=9322`, set `TAKT_TEST_CONFIG` to a private bundled setup JSON file and `TAKT_PLAYWRIGHT_MODULE` to an installed Playwright 1.62.1 module (or install Playwright separately for QA). Run the test with Node. It uses gpt-6.1-sol, sends two paid prompts, tests terminal commands/resize/close and captures rendered replies. It configures the application user's actual agent data. Close the test app and reopen without debugging arguments when done. Running the EXE with PATH containing only Windows system directories verifies it does not rely on globally installed Node or pi.
